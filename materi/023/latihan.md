# Soal Latihan PHP: Program Data Sederhana

---

## **Soal 1: Program Data Siswa**

**Studi Kasus:**  
Kamu diminta membuat program sederhana untuk mencatat data siswa di sebuah kelas. Setiap siswa memiliki **nama** dan **nilai akhir**. Program harus bisa menampilkan daftar siswa, menambahkan siswa baru, dan keluar dari program.

**Instruksi:**

1. Buat array `$siswa` yang berisi beberapa siswa contoh.
2. Buat menu dengan opsi:
   - 1. Lihat Daftar Siswa
   - 2. Tambah Siswa
   - 3. Keluar Program
3. Jika memilih opsi 1, tampilkan nama dan nilai setiap siswa.
4. Jika memilih opsi 2, minta input nama dan nilai siswa, lalu tambahkan ke array.
5. Program terus berjalan hingga pengguna memilih opsi 3.

**Instruksi:**

2. Buat menu dengan opsi:
   - 1. Lihat Daftar Alat
   - 2. Tambah Alat
   - 3. Keluar Program
3. Jika memilih opsi 1, tampilkan nama alat dan stoknya.
4. Jika memilih opsi 2, minta input nama alat dan jumlah stok, lalu tambahkan ke array.
